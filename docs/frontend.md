# رابط عمومی M3

فرانت‌اند با Next.js App Router، TypeScript و Tailwind CSS ساخته شده و همه مسیرهای P0 فارسی، راست‌به‌چپ و واکنش‌گرا هستند.

## مسیرها

- `/` صفحه اصلی و معرفی مسیر همکاری
- `/about` و `/certificates` معرفی و مدارک قابل انتشار
- `/services` و `/services/[slug]` خدمات و جزئیات
- `/products` و `/products/[slug]` جستجو، فیلتر، صفحه‌بندی و استعلام تک‌محصولی
- `/projects` و `/projects/[slug]` پروژه‌ها و روایت مسئله، اقدام و نتیجه
- `/consultation` فرم مشاوره
- `/contact` و `/privacy` ارتباط و حریم خصوصی

داده‌ها از `NEXT_PUBLIC_API_BASE_URL` خوانده می‌شوند. صفحات محتوایی در صورت در دسترس نبودن API، empty state صریح نمایش می‌دهند. فرم‌ها خطای اعتبارسنجی و کد پیگیری موفق را به‌صورت قابل دسترس اعلام می‌کنند.

هیچ اطلاعات تماس، مدرک، مشتری، آمار یا نتیجه واقعی در فرانت‌اند hardcode نشده است. این موارد باید از محتوای تأییدشده Django Admin تأمین شوند.
