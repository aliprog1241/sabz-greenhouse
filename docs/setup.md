# راه‌اندازی توسعه

## پیش‌نیازها

- Python 3.12 یا جدیدتر سازگار با Django 6.1
- Node.js 20.9 یا جدیدتر؛ استفاده از نسخه LTS توصیه می‌شود
- Docker Desktop برای PostgreSQL
- Git و PyCharm

دستورهای کامل در README قرار دارند. برای PyCharm، interpreter را روی `.venv\Scripts\python.exe` تنظیم کنید و دو Run Configuration جدا برای `backend/manage.py runserver` و `npm run dev` بسازید.
