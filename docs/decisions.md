# تصمیم‌ها و ابهام‌های پروژه

## تصمیم‌های ثبت‌شده

- نام Sabz Greenhouse موقت است.
- رابط عمومی فارسی و راست‌به‌چپ است.
- پرداخت، حساب مشتری، OTP و سبد خرید در MVP وجود ندارد.
- هر استعلام دقیقاً به یک محصول مربوط است.
- PostgreSQL در توسعه و تولید الزامی است و fallback پنهان SQLite نداریم.
- مدیریت محتوا و سرنخ‌ها با Django Admin انجام می‌شود.
- PDF ارائه فقط مرجع بصری است و منبع کد فرانت‌اند نیست.

## اطلاعات تأییدنشده

- نام تجاری، دامنه و لوگوی نهایی
- تلفن، ایمیل و نشانی رسمی
- رزومه و مدارک قابل انتشار امیررضا قشنی
- فهرست واقعی محصولات و مجوزهای عرضه
- هاست، ذخیره‌سازی رسانه و سیاست بکاپ نهایی

تا زمان تأیید، این موارد باید placeholder یا داده دارای برچسب DEMO باشند.

## تصمیم‌های فنی M1

- وضعیت انتشار محتوای عمومی `DRAFT` یا `PUBLISHED` است.
- پروژه، گواهی و مقاله می‌توانند صریحاً با `is_demo` علامت‌گذاری شوند.
- حذف دسته دارای محصول و محصول دارای استعلام با `PROTECT` مسدود می‌شود.
- SQLite فقط در `config.settings_test` برای تست خودکار حافظه‌ای استفاده می‌شود؛ تنظیمات اصلی همواره PostgreSQL است.
