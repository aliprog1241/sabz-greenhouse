# Sabz Greenhouse Frontend

رابط عمومی فارسی و RTL پروژه با Next.js App Router، TypeScript و Tailwind CSS.

```powershell
npm install
npm run dev
```

متغیر `NEXT_PUBLIC_API_BASE_URL` باید به مسیر `/api/v1` بک‌اند اشاره کند. برای کنترل کیفیت:

```powershell
npm run lint
npm run build
```

جزئیات مسیرها و تصمیم‌های رابط در `../docs/frontend.md` ثبت شده است.
